# Ecommerce Analytics Dashboard
### Tracy Sandoval - C964 Capstone Part C

## Step 1. Open the codebase locally
### Unzip the folder containing the codebase, and open the unzipped project in your IDE

## Step 2. Run the project
### Open a terminal and run
    npm run dev
### Using turborepo I have it set up so that this one command starts up the frontend and backend together

## Step 3. Test the application in the browser
### You can now open the project in the browser at
    http://localhost:5173/
### This is also provided as a link in the terminal when you run the project, so all you need to do is ctrl click the link
